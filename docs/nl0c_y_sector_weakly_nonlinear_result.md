## C6. No ordinary global bilinear F2 kernel for the MOND vertex

The map

\[
\mathbf g\mapsto |\mathbf g|\mathbf g
\]

is homogeneous of degree two,

\[
|\epsilon\mathbf g|(\epsilon\mathbf g)
=\epsilon^2|\mathbf g|\mathbf g
\quad (\epsilon>0),
\]

but it is not a quadratic form and is not generated by a field-independent symmetric bilinear map at \(\mathbf g=0\). Its second directional derivative at the zero-gradient state depends on the direction in field space.

Consequently the leading MOND correction is genuinely second order in amplitude but cannot, in general, be represented by a standard SPT expression

\[
\delta^{(2)}(\mathbf k)
=\int d^3q\,F_2(\mathbf q,\mathbf k-\mathbf q)
\delta^{(1)}(\mathbf q)\delta^{(1)}(\mathbf k-\mathbf q)
\]

with one universal field-independent bilinear kernel for this vertex.

A Fourier transform can still be used numerically, but the nonlinear operation itself must be evaluated in real space (or through an equivalent directional/homogeneous formulation) before transforming back.

This changes the NL1 implementation plan: **NL1 is a weakly nonlinear real-space pseudo-spectral evolution, not a conventional F2-only SPT calculation.** Standard analytic quadratic vertices from the metric/aether/Q-sector can still be handled spectrally; the MOND \(|\nabla\chi|\nabla\chi\) vertex is evaluated pointwise in real space.

**C6: PASS.**
