# C3 R5 post-data scale/sign diagnostic

This is a diagnostic analysis of the already observed R5 C3 failure from run 34496088156. It is not a new preregistered scientific gate and cannot alter the historical R5 classification.

Frozen input for this diagnostic is the R5 zero-coupling-safe CLASS tangent reference and the unchanged D2C6C offline linear tangent implementation at Nx=128, Nstep=4096, bath order 39.

For alpha, E and chi, the offline spatial tangent fields are projected back onto the exact six-mode field basis generated by `m.to_field`. For each field and each of the six frozen modes, and also globally over all mode/checkpoint values, fit the signed scalar

s = <T_CLASS,T_offline>/<T_CLASS,T_CLASS>

which minimizes ||T_offline-s T_CLASS||_2. Report s, cosine similarity, and the residual after optimal scaling relative to the offline norm. Also report the inverse least-squares scale mapping offline to CLASS.

Interpretation is diagnostic only:
- |cosine| near 1 with small scaled residual and nearly common s indicates a normalization/sign bridge issue.
- materially varying s or large scaled residual indicates a shape/dynamics mismatch.

No equations, physical parameters, finite-eta scope, original C3 threshold (5e-3), historical R2/R3/R4/R5 outcomes, or licensing status are changed. Finite-positive-eta nonlinear memory remains unlicensed.
