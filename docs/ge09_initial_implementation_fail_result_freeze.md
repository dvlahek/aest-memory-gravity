## Failure

The driver attempted to pass the already frozen p3 precision values through
`classy.Class.set()`:

- `tol_perturb_integration`;
- `perturb_sampling_stepsize`.

Pinned CLASS/classy rejected both as unread input parameters before
perturbation integration began:

`Class did not read input parameter(s): tol_perturb_integration, perturb_sampling_stepsize`.

Thus the failure is an execution-surface incompatibility.

It is not:

- a local-jet failure;
- an interpolation failure;
- a source-grid validation failure;
- a physical-RHS failure;
- a matter-closure result.
