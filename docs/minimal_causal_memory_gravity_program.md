# Minimal Causal Memory Gravity (MCMG)

## Scientific objective

The primary object is gravitational memory itself, not AeST. AeST is retained only as an independent host realization and stress test.

The program asks a narrower and stronger question:

> Can a finite causal response time of gravity leave a universal, stable, and observable signature in cosmological perturbations while the static and instantaneous limits remain exactly GR?

The target is a host-independent result suitable for a broad physics audience. The strongest outcome is not an arbitrary nonlocal modification, but a causal memory principle that predicts a joint time-dependent relation between structure growth and gravitational lensing.

## Why this is not simply another nonlocal-gravity model

Nonlocal and retarded gravity already exist in the literature (e.g. Deser-Woodard, Mashhoon constitutive nonlocal gravity, and RR/RT-type models). Therefore novelty cannot be the statement that gravity may be nonlocal in time.

The distinguishing construction here is a **pure-memory deformation**: the correction is the difference between a retarded state and the instantaneous state. Consequently the correction vanishes in the static limit and in the zero-memory-time limit.

For any scalar gravitational source S(t), define

    M(t) = integral_0^infinity K(s) S(t-s) ds,

with K(s) causal, normalized, non-negative in the baseline model, and with finite moments. The pure-memory response is

    Delta_mem(t) = M(t) - S(t).

The gravitational response is deformed as

    G_eff[S](t) = S(t) + eta Delta_mem(t).

Therefore

    eta = 0        -> GR,
    tau_mem -> 0   -> GR,
    dS/dt = 0      -> GR after transients.

This isolates memory from a static change of Newton's constant or a static modified-gravity force law.

## Minimal one-pole realization

For an exponential causal kernel,

    K(s) = exp(-s/tau_mem)/tau_mem,

M is represented locally by

    tau_mem dM/dt + M = S.

In N = ln a,

    epsilon(a) M' + M = S,
    epsilon(a) = H(a) tau_mem.

For slowly evolving sources,

    M - S = -tau_bar dS/dt + (mu_2/2) d^2S/dt^2 + ...,

where tau_bar is the first moment of the kernel. Thus the leading memory signal depends only on the mean causal delay, not on the detailed kernel shape.

This moment expansion is the first candidate universal result of the program.

## Cosmological scalar-sector baseline

Use flat LambdaCDM expansion as a fixed background in the first host-independent stage. Let D(a) be the linear matter-growth amplitude and define the GR-like potential source

    P(a) = D(a)/a.

This choice is deliberate: P is constant in exact Einstein-de Sitter growth, so a pure temporal-memory correction vanishes there at leading order and activates when the potential evolves.

Introduce the memory state

    H tau_mem M' + M = D/a.

The effective potential source is

    P_eff = (1-eta) D/a + eta M.

The coupled growth equation is

    D'' + [2 + H'/H] D' - (3/2) Omega_m(a) [(1-eta)D + eta a M] = 0.

No-slip is the minimal baseline, so the same P_eff controls the Weyl potential. Slip, scale dependence, and covariant embeddings are later extensions and must not be introduced before the minimal gates close.

## Central prediction: gravitational hysteresis

A causal memory state does not respond to the instantaneous source alone. The pair (P, M) traces a history-dependent trajectory. In the slow-memory limit,

    Delta_mem ~ -tau_bar dP/dt.

Hence memory is naturally small when the gravitational potential is stationary and becomes largest during epochs in which the potential changes. This produces a redshift-dependent lag between the matter distribution and the metric response.

The intended observable is not a free mu(a,k) curve. It is a constrained relation between

- growth of matter perturbations,
- the Weyl/lensing potential,
- and their redshift evolution,

all generated by the same causal kernel moments.

A successful program should derive a low-dimensional **memory consistency relation** connecting growth and lensing responses. That relation, rather than AeST-specific parameters, is the main candidate Nature-level result.

## Connection to the completed AeST program

The existing AeST work is retained as independent evidence and as a later realization test. It has already developed the technical machinery for finite eta, finite memory time, time-dependent H, evolving/background-tracking memory, response/tangent calculations, growth, and lensing projections. Historical classifications remain unchanged.

The current AeST fine-k/ULP issue is not imported into the minimal model. It is treated separately as a host-specific numerical/stability audit. MCMG must stand without AeST.

If the same host-independent memory consistency relation later appears in AeST with finite memory, AeST becomes evidence of generality rather than a single point of failure.

## Nature-level line

The desired logical chain is

    causality
      -> finite gravitational response time
      -> universal first-moment response
      -> gravitational hysteresis
      -> linked growth + lensing signature
      -> observational constraint/detection.

The strongest possible claim would be that cosmological data constrain or prefer a nonzero gravitational response time through a relation that cannot be reproduced by an arbitrary instantaneous rescaling without violating the causal-response consistency relation.

A second strong outcome is that finite memory regularizes a host theory's unstable/ill-conditioned instantaneous response while preserving the same host-independent growth-lensing relation.

## Guardrails

1. No new-physics claim from AeST ULP sensitivity.
2. No observational claim before standalone MCMG numerical controls pass.
3. GR, zero-memory-time, and static-source limits are hard gates.
4. Kernel-shape claims require fixed first moment and multiple causal kernels.
5. Any claimed stability effect must be reproduced from an equation-level eigenmode or energy analysis, not only from a Boltzmann code.
6. Any Nature claim requires host independence plus an observable consequence.
7. Historical preregistered AeST failures remain historical failures and are never retroactively reclassified.

## Planned sequence

### MCMG-R1: universal causal-memory response

Prescribed LambdaCDM source P_GR(a)=D_GR(a)/a. Compare several normalized causal kernels with the same first moment. Test the derivative/moment expansion, causality, zero-memory limit, and kernel-shape collapse.

### MCMG-R2: self-consistent growth + Weyl system

Solve the coupled (D,M) system. Measure growth response, Weyl response, phase/lag proxy, stability, and the eta/tau tangent limit. Verify that finite response converges to the R1 low-memory prediction.

### MCMG-R3: memory consistency relation

Derive and numerically validate a relation linking growth and Weyl/lensing responses. Test robustness to kernel shape and background cosmological parameters.

### MCMG-R4: independent host realization

Map the same response quantities onto AeST finite-memory runs only after its numerical stability audit is closed. The host-independent relation is frozen before looking at AeST results.

### MCMG-R5: observational projection

Project the minimal model into linear CMB lensing and low-redshift growth observables. Use the same causal-memory parameters for both. No nonlinear/Halofit claim until the linear sector is closed.

### MCMG-R6: data test

Joint fit to lensing and growth data. The primary question is whether one causal-memory response can account for both sectors better than the nested GR limit, with appropriate complexity penalties and held-out checks.

## Literature boundary

The project must explicitly distinguish itself from:

- Deser & Woodard nonlocal cosmology: delayed/nonlocal curvature response;
- Mashhoon nonlocal gravity: constitutive-kernel formulation and dark-matter-like response;
- RR/RT infrared nonlocal gravity: specific inverse-d'Alembertian effective models and cosmological fits.

MCMG does not claim that retarded gravity is new. The candidate novelty is the pure-memory GR-static-limit construction, the universal kernel-moment expansion, and the resulting joint growth-lensing causal consistency relation.
