# NL1C6D1 dynamical derivation audit

This document records what can be derived directly from the published AeST theory before any nonlinear dynamical branch-selection experiment. It is an audit document under `NL1C6D1_PREDATA_DYNAMICAL_FORMULATION_AUDIT`, not a result classification.

## 1. Covariant starting point

Skordis & Zlosnik (Phys. Rev. D 106, 104041, 2022) write AeST in terms of the metric `g_{mu nu}`, a unit timelike vector `A^mu`, and a scalar `phi`. In their convention the action contains

```text
R - 2 Lambda
- (K_B/2) F^{mu nu} F_{mu nu}
+ 2(2-K_B) J^mu nabla_mu phi
- (2-K_B) Y
- F(Y,Q)
- lambda(A^mu A_mu + 1),
```

with

```text
Q = A^mu nabla_mu phi,
Y = (g^{mu nu}+A^mu A^nu) nabla_mu phi nabla_nu phi,
J^mu = A^nu nabla_nu A^mu.
```

The unit-vector condition is therefore a true constraint, not an optional numerical normalization.

At the late-time Minkowski tracking background used for the stability analysis,

```text
g_{mu nu} = eta_{mu nu},
A^mu = (1,0,0,0),
phi = Q0 t + varphi.
```

Around the minimum in `Q`, the free function has the quadratic expansion

```text
F = (2-K_B) lambda_s Y - 2 K2 (Q-Q0)^2 + higher order terms.
```

The MOND/nonlinear spatial contribution begins beyond this quadratic action and therefore does not alter the leading linear normal-mode dispersion.

## 2. Scalar gauge sector

Using scalar-vector-tensor decomposition, the longitudinal part of the spatial vector perturbation is written

```text
A_i = grad_i alpha + transverse part.
```

Under an infinitesimal time diffeomorphism generated by `xi_T`,

```text
alpha -> alpha - xi_T,
varphi -> varphi + Q0 xi_T.
```

Hence the published gauge-invariant scalar combination is

```text
chi = varphi + Q0 alpha.
```

This is the direct theoretical ancestor of the weak-field `chi` used by the repository. It is important that `chi` is a combination of the scalar and longitudinal vector sectors. Evolving `chi` by an independently invented scalar PDE would in general discard information carried by the separate canonical variables and constraints.

The scalar metric perturbations may be represented in Newtonian gauge after setting the scalar shear/shift gauge variables to zero. The stability calculation then starts from the coupled scalar variables `{Psi, Phi, alpha, varphi}` and eliminates nondynamical constraints before identifying physical normal modes.

## 3. Linear scalar normal modes

For vanishing matter source, the determinant of the scalar linear system gives two scalar dispersion branches:

```text
omega^2 = 0,
omega^2 = c_s^2 k^2 + M^2.
```

The propagating branch has

```text
c_s^2 = (2-K_B)/(K2 K_B) * (1 + 0.5 K_B lambda_s),
M^2   = (2-K_B)(1+lambda_s) Q0^2/K_B.
```

The second branch is non-propagating at this order and must not be silently replaced by damping or discarded when reconstructing the full constrained system. The Hamiltonian analysis of the same scalar sector shows that the propagating massive mode is a genuine physical degree of freedom after constraint elimination.

For D1B we therefore evolve only the already reduced propagating normal coordinate `X_k` as a regression target. This tests the published dispersion relation but does not yet constitute the nonlinear physical evolution required for D2.

```text

j(x) -> 1/beta0  for large x.
```

## 5. Static mass is not the propagating mass

The weak-field quasistatic equations use

```text
mu^2 = 2 K2 Q0^2/(2-K_B).
```

For the frozen repository values,

```text
mu^2 = 9.826739074217741e-5 Mpc^-2,
mu   = 9.912991008882103e-3 Mpc^-1.
```

This is distinct from the normal-mode `M` above. No D1 or D2 code may replace one with the other without an explicit derivation.

## 6. Quasistatic nonlinear endpoint

Verwayen, Skordis & Boehm (MNRAS 531, 272-289, 2024) obtain the static weak-field system after neglecting time derivatives. In the notation already frozen in the repository,

```text
Phi = tildePhi + chi,
laplacian(tildePhi) + mu^2 Phi = 4 pi G_N rho_b/(1+beta0),
laplacian(tildePhi) = div[j(x) grad chi],
x = |grad chi|/a0
```

with the repository's explicit conversion to physical-coordinate acceleration units. Their high-gradient limit is `j -> 1/beta0`, and the nonlinear choices used by NL1C6R3 are the same simple, exponential and sharp interpolation families.

Thus the D1-D target is well founded: any legitimate time-dependent reduction used for D2 must reduce to exactly this system when its time derivatives are set to zero.

## 7. What is NOT yet derived

The published sources establish all of the following:

1. the full covariant AeST action;
2. the non-perturbative constraint structure;
3. the linear scalar variables and gauge-invariant `chi`;
4. the constraint-reduced propagating scalar dispersion;
5. the nonlinear quasistatic spatial equations and their full `j(x)` dependence.

They do **not**, in the form used by the present repository, hand us a closed nonlinear time-dependent weak-field PDE involving only `{Phi, tildePhi, chi}` for arbitrary full `j(x)`.

Therefore the following shortcut is forbidden:

```text
chi_tt + Gamma chi_t + R_static[chi] = 0
```

or any equivalent pseudo-time relaxation invented from the R3 residual.

A model-consistent nonlinear D2 system must instead be obtained by reducing the covariant or 3+1 equations while retaining enough of the longitudinal vector/scalar variables and solving the true nondynamical constraints. Only after that reduction may variables be combined into the repository `chi`.
