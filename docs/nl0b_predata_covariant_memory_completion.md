## Frozen candidate

\[
h_{\mu\nu}=g_{\mu\nu}+A_\mu A_\nu,
\qquad
X_\mu=h_\mu{}^\nu\nabla_\nu\phi.
\]

\[
A^\mu U_{j\mu}=0,
\]

\[
\mathscr D_A U_{j\mu}
\equiv h_\mu{}^\nu A^\rho\nabla_\rho U_{j\nu}.
\]

\[
S_{\rm mem}=\frac{1}{16\pi\tilde G}

\left[
