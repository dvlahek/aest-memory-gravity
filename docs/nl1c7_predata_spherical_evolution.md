## Pre-registered diagnostics and gates

### G1 — provenance
Parent NL1C6 run/head/artifact digest must match exactly.

### G2 — initial-data closure
Regular center and asymptotic-background boundary conditions must produce finite eta=0 initial data on both grids with no added physical closure.

### G3 — initial constraints
Normalized Hamiltonian and radial-momentum constraint residuals must each be `<= 1e-7` on both grids after excluding only the analytically regular center point.

### G4 — regularity / ordering
Throughout the certified interval all evolved primitive fields must remain finite, areal radius must be non-negative, and the radial map must remain ordered. A first loss of ordering is classified as shell/coordinate crossing and terminates certification at that time; it is not numerically patched.

### G5 — constraint propagation
Before any physical turnaround/collapse interpretation, RMS normalized Hamiltonian and momentum residuals must stay `<= 1e-5`; maximum normalized residuals must stay `<= 1e-4` on the primary and control run.

### G6 — grid convergence
For common times before the earliest termination event, the L2 relative differences between `Nr=256` and `Nr=512` for areal radius, radial velocity, matter density, scalar field and aether rapidity must be `<= 2e-2`. Constraint RMS values must agree within a factor of 2.

### G7 — homogeneous-background control
A separate `delta0=0` eta=0 run using the same numerical method must preserve the homogeneous expanding solution to L2 relative error `<= 1e-5` over the certified interval.

### G8 — turnaround reporting
If a shell changes from expansion to infall before the earliest termination event, report its first turnaround time/scale factor and areal radius. Turnaround is a reporting quantity, not itself a pass/fail requirement. No shell may be selected after inspecting the result; report the earliest turnaround across the frozen radial grid and its radial index/location.

### G9 — collapse/shell-crossing reporting
If an areal-radius collapse threshold or radial-map crossing is reached, report the first event and stop. NL1C7 does not continue through shell crossing and does not introduce a virialization prescription.
