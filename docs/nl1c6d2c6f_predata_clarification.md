# NL1C6D2C6F pre-run clarification — source signature and comparison norm

This clarification is committed before any D2C6F numerical run/output is inspected. It changes no physics, eta value, completion member, resolution or gate threshold from `docs/nl1c6d2c6f_finite_eta_gravitational_source_predata.md`.

For F6--F8, each stored source field is transformed with the normalized periodic real FFT `rfft(S)/Nx`. The common signature contains Fourier indices `n=0,...,32` at every stored redshift checkpoint. These modes exist identically on both `Nx=128` and `Nx=256` grids and include the zero mode generated by the quadratic direct stress.

For source block `A` and control block `B`, the relative L2 discrepancy is frozen as

`||A-B||_2 / max(||A||_2, ||B||_2, 1e-300)`.

The bath, time and space gate value is the worst discrepancy over the four preregistered action-source combinations `S_Psi`, `S_Phi`, `S_b`, `S_shear` and all 27 completion members.

Checkpoint bath variables are linearly interpolated between the same RK4 endpoint states used by the parent D2C6D/E checkpoint interpolation. This interpolation is diagnostic bookkeeping only and does not feed back into the integration.

The D2C6C--E internal bath variable is `z_j`; the action variable is reconstructed using the already certified bridge

`z_j = omega_j q_j / (k sqrt(w_j))`,

implemented spectrally with `sqrt(-laplacian)` on the periodic box. No additional normalization is introduced.
