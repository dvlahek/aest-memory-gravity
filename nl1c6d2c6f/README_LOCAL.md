# D2C6F local run

D2C6F evaluates the direct finite-eta gravitational source generated by the frozen NL0B memory action on the already certified D2C6E retained scalar-current trajectories.

It is intentionally local-only. No GitHub Actions workflow is provided.

## Run

From the repository root on branch `v053-exp-normalization-corrected`:

```bash
git pull
bash nl1c6d2c6f/run_local.sh
```

The runner reuses `.local/d2c6e_venv` and the zero-safe CLASS build produced by D2C6E when they are valid on the current machine. Otherwise it recreates them without changing the frozen science configuration.

## Outputs

- `results/nl1c6d2c6f_finite_eta_gravitational_source.log`
- `results/nl1c6d2c6f_finite_eta_gravitational_source.json`
- `results/nl1c6d2c6f_local_bundle.zip`

Send the ZIP bundle for interpretation. The bundle is produced even when the scientific classification is FAIL or the run becomes technically INCOMPLETE.
