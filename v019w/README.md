# v0.19w — variational tangent forcing at eta=0

v0.19v showed that the signed finite-difference CMB tangent is limited by subtraction noise even though the Exp tauH0=1 bath-order and CLASS precision controls pass. v0.19w therefore removes finite eta from the tangent extraction.

At eta=0 the memory bath is driven by the unperturbed AeST scalar trajectory, while its feedback into the E closure vanishes. If B_chi^(0) denotes the unscaled bath response on that trajectory, the exact parameter forcing in conformal time is

    f_E(k,tau) = (partial E'/partial eta)|_0
               = - a Q B_chi^(0) / (2 K_B).

The base run records this forcing on the native CLASS source-sampling grid. A second CLASS pass evolves the same linear Boltzmann/AeST system with the physical memory feedback disabled and an external tangent forcing lambda*f_E added only to the E equation. Since the perturbation system is linear,

    X_lambda = X_0 + lambda S_eta,

where S_eta is the exact first-order state sensitivity generated by f_E. The signed lambda is only a scale factor for the tangent source; it is not a physical negative memory coupling.

For unlensed spectra the transfer-to-C_l map is quadratic, so

    [C_l(+lambda)-C_l(-lambda)]/(2 lambda)

is independent of lambda in the ideal variational system and equals dC_l/deta at eta=0. This provides a high-signal tangent extraction without subtracting two nearly identical finite-eta cosmologies.

Primary gates:

- lambda invariance of the unlensed TT/EE/TE tangent for lambda=1,10,30;
- N=39 versus N=47 convergence of the recorded eta=0 forcing;
- p3 versus p4 convergence of the forcing and the lambda=10 tangent;
- eta=0 baseline agreement between the traced memory-enabled run and the externally forced tree at lambda=0;
- non-zero tangent signal.

The first v0.19w gate is intentionally unlensed. Lensing differentiation is deferred until the primary linear Boltzmann tangent is validated.
